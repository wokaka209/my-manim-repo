# 数字 PID 控制 · Manim 动画场景文档

> **项目**：数字 PID 控制算法可视化动画  
> **引擎**：Manim Community v0.18+  
> **风格**：深色科技风 · 与 `pid_control.py` 统一视觉语言  
> **定位**：教学科普，侧重**离散化**本质与**增量式/位置式**对比  
> **总时长**：约 2 分 30 秒（15fps 渲染）

---

## 一、与模拟 PID 的核心区别

| 维度 | 模拟 PID | 数字 PID |
|------|---------|---------|
| 自变量 | 连续时间 t | 离散采样时刻 k |
| 积分 | ∫e(t)dt | Σe[k]·Tₛ |
| 微分 | de(t)/dt | (e[k]-e[k-1])/Tₛ |
| 输出 | 连续信号 u(t) | 离散序列 u[k] |
| 实现 | 运放电路 | 微处理器代码 |

### S1 · 开场 `scene_intro`

**目的**：建立"从模拟到数字"的叙事线

#### 动画序列

| 时间 | 动作 | 视觉元素 |
|------|------|----------|
| 0–1.5s | 标题弹入 | "数字 PID 控制" 大字 + 缩放弹性动画 |
| 1.5–4s | P / I / D 三字母逐个点亮 | 与模拟版相同风格，但字母带有"方波"装饰暗示离散 |
| 4–7s | 连续→离散过渡 | 一条正弦曲线逐步变成阶梯状（零阶保持效果） |
| 7–10s | 副标题 + 离散公式闪现 | `u[k] = Kp·e[k] + Ki·Σe + Kd·(e[k]-e[k-1])` |

#### 关键视觉

- 连续→离散过渡是本场景的核心教学点
- 用曲线→阶梯的动画直观展示"采样"概念
- 标注"连续域 t → 离散域 k"

### S2 · 采样与保持 `scene_sampling`

**目的**：理解数字控制的基础——采样、量化、零阶保持

#### 动画序列

| 时间 | 动作 | 视觉元素 |
|------|------|----------|
| 0–2s | 场景标题 | "从连续到离散：采样与保持" |
| 2–6s | 采样过程动画 | 连续曲线上逐个出现采样点（紫色圆点），竖线标记采样时刻 |
| 6–10s | 零阶保持动画 | 采样点之间连成水平阶梯线（青色），与原曲线对比 |
| 10–14s | 采样周期标注 | Tₛ 标注，"采样频率越高→阶梯越接近原曲线" |
| 14–16s | 退场 | 淡出 |

#### 关键实现思路

- 连续曲线用 `axes.plot()` 绘制
- 采样点用 `Dot` 在曲线上标记
- 零阶保持用阶梯函数 `axes.plot()` 或 `VGroup(Line, Line, ...)` 绘制
- Tₛ 用 `DoubleArrow` + 标注

### S3 · 位置式 PID `scene_position_pid`

**目的**：推导位置式（绝对式）数字 PID 公式

#### 动画序列

| 时间 | 动作 | 视觉元素 |
|------|------|----------|
| 0–2s | 标题 | "位置式 PID" + 副标题"输出 = 绝对位置" |
| 2–5s | 连续公式回顾 | u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt |
| 5–9s | 离散化替换动画 | 积分→求和（∫→Σ），微分→差分（d/dt→Δ/Tₛ），t→k |
| 9–14s | 位置式公式呈现 | u[k] = Kp·e[k] + Ki·Tₛ·Σe[j] + Kd·(e[k]-e[k-1])/Tₛ |
| 14–18s | 特征标注 | "输出是全量" / "需要存储所有历史误差" / "积分饱和风险" |

#### 关键公式

$$u[k] = K_p \cdot e[k] + K_i \cdot T_s \sum_{j=0}^{k} e[j] + K_d \cdot \frac{e[k] - e[k-1]}{T_s}$$

---

### S4 · 增量式 PID `scene_incremental_pid`

**目的**：推导增量式（相对式）数字 PID 公式

#### 动画序列

| 时间 | 动作 | 视觉元素 |
|------|------|----------|
| 0–2s | 标题 | "增量式 PID" + 副标题"输出 = 增量Δu" |
| 2–6s | 从位置式做差 | u[k] - u[k-1] 展开动画 |
| 6–12s | 增量式公式呈现 | Δu[k] = Kp·(e[k]-e[k-1]) + Ki·Tₛ·e[k] + Kd·(e[k]-2e[k-1]+e[k-2])/Tₛ |
| 12–16s | 递推动画 | 逐步计算演示：e[k-2], e[k-1], e[k] 三个误差值滚动 |
| 16–18s | 特征标注 | "只输出增量" / "只需存最近3个误差" / "无积分饱和" / "切换无冲击" |

#### 关键公式

$$\Delta u[k] = K_p(e[k]-e[k-1]) + K_i T_s e[k] + \frac{K_d}{T_s}(e[k]-2e[k-1]+e[k-2])$$

$$u[k] = u[k-1] + \Delta u[k]$$

### S5 · 位置式 vs 增量式对比 `scene_position_vs_incremental`

**目的**：直观对比两种实现方式的差异

#### 动画序列

| 时间 | 动作 | 视觉元素 |
|------|------|----------|
| 0–2s | 标题 | "位置式 vs 增量式" |
| 2–10s | 左右分屏对比 | 左侧位置式框图 + 右侧增量式框图 |
| 10–14s | 关键差异高亮 | 积分项对比：位置式累加 vs 增量式差分 |
| 14–16s | 总结表格 | 5行对比表（输出、存储、积分饱和、切换冲击、抗干扰） |

#### 对比表格

| 特性 | 位置式 | 增量式 |
|------|--------|--------|
| 输出 | 全量 u[k] | 增量 Δu[k] |
| 存储需求 | 所有历史误差 e[0]~e[k] | 最近 3 个误差 |
| 积分饱和 | 有风险 | 无 |
| 手动/自动切换 | 有冲击 | 无冲击 |
| 抗积分饱和 | 需额外处理 | 天然免疫 |

### S7 · 代码实现 `scene_code_implementation`

**目的**：展示数字 PID 的伪代码/代码实现

#### 动画序列

| 时间 | 动作 | 视觉元素 |
|------|------|----------|
| 0–2s | 标题 | "代码实现" |
| 2–8s | 位置式伪代码逐行打出 | 类似终端打字效果，语法高亮 |
| 8–14s | 增量式伪代码逐行打出 | 同上，对比展示 |

#### 位置式伪代码

```c
// 位置式 PID
error = setpoint - measurement;
integral += error * Ts;
derivative = (error - prev_error) / Ts;
output = Kp * error + Ki * integral + Kd * derivative;
prev_error = error;
```

#### 增量式伪代码

```c
// 增量式 PID
error = setpoint - measurement;
delta = Kp*(error-prev_error) 
      + Ki*Ts*error 
      + Kd/Ts*(error-2*prev_error+prev_prev_error);
output += delta;
prev_prev_error = prev_error;
prev_error = error;
```

## 六、视觉风格备注

1. **深色背景** `#0d1117` 贯穿始终，与 `pid_control.py` 统一
2. **P/I/D 三色**保持一致（珊瑚红/青绿/琥珀黄）
3. **新增数字化特色色**：采样紫 `#BC8CFF`、保持青 `#39D2C0`、代码绿 `#7EE787`
4. **采样点**统一用紫色圆点 + 竖虚线标记
5. **零阶保持**统一用青色阶梯线
6. **代码展示**用终端风格黑底绿字，等宽字体 Monaco
7. **公式**统一使用 `MathTex`，字号 ≥ 28
8. **布局边界**：所有元素坐标在 x ∈ [-6.5, 6.5]、y ∈ [-3.5, 3.8]
9. **教育风格**：大字体、有序出入场、元素不重叠
